# Методичка студенту: лаборатория по подделке JWT

## Сценарий

Вам выдан скомпилированный десктопный клиент (на Windows `ApiClient.exe`, на macOS/Linux
`ApiClient`), который обращается к удалённому API. Клиент аутентифицируется через JWT.
Ваша цель — перехватить трафик клиента и подделать токены для эндпоинтов, доступ к которым
вам не положен.

Исходный код сервера и его секреты вам НЕ выданы. Всё необходимое находится внутри
бинарника клиента и в сетевом трафике.

## Инструменты

- Wireshark (перехват сети)
- Выданный вам клиент (`ApiClient.exe` в Windows или `ApiClient` в macOS/Linux)
- https://jwt.io (декодирование/просмотр)
- CyberChef (base64url, HMAC, AES-GCM)
- `strings` или `pyinstxtractor` (анализ клиента)

Скрипты запускаются одинаково на всех платформах, примеры команд `python ...` работают и
как `.venv/bin/python ...` (macOS/Linux), и как `.venv\Scripts\python ...` (Windows).

## Подготовка

1. Запустите клиент и запомните URL API, показанный сверху.
2. Запустите Wireshark и начните перехват на интерфейсе, через который идёт трафик клиента.
3. Если туннель работает по обычному HTTP, вы прочитаете токены напрямую. Если адрес
   `127.0.0.1`, перехватывайте на loopback-адаптере (в Wireshark: Adapter for loopback
   traffic) либо на машине, где размещён сервер.

## Важно: jwt.io умеет только подписанные токены

jwt.io декодирует **JWS** (3 сегмента, подпись). Эндпоинт `/private/encrypted` использует
**JWE** (5 сегментов, шифрование), поэтому при вставке туда вы увидите
`Invalid Compact JWS` — это ожидаемо, а не ваша ошибка. Для эндпоинта 5 используйте
хелпер ниже:

```
python scripts/jwe_helper.py decode "<jwe-токен>"
python scripts/jwe_helper.py forge --role admin --sub hacker
```

## Задача 1 — Публичный эндпоинт

Нажмите `/public`. Убедитесь, что заголовок `Authorization` не отправляется.

Ожидаемый артефакт: JSON-приветствие и время сервера.

## Задача 2 — Неподписанный токен (`/private/none`)

1. Нажмите `/private/none` и скопируйте токен из блока «Generated token».
2. Вставьте его на https://jwt.io. Обратите внимание на заголовок: `{"alg":"none"}` и
   завершающую точку.
3. Измените payload: поставьте `role` в `admin` и `sub` на своё имя.
4. Пересоберите токен как `base64url(header).base64url(payload).` (сохраните завершающую
   точку, `alg` оставьте `none`, подписи нет).
5. Отправьте его через клиент или `curl`:

   ```
   curl -H "Authorization: Bearer <ваш-токен>" <API_URL>/private/none
   ```

Ожидаемый артефакт: сервер принимает изменённые claims и возвращает их обратно.

## Задача 3 — Повышение до админа (`/private/admin`)

То же, что в задаче 2, но цель — `/private/admin` с `"role":"admin"` в payload.

Ожидаемый артефакт: `200 OK` с админским доступом по токену, который вы собрали сами.

## Задача 4 — Взлом подписи (`/private/signed`)

1. Нажмите `/private/signed` и перехватите HS256-токен.
2. Восстановите секрет офлайн-подбором (без анализа клиента). Предоставленный скрипт
   пробует список частых/слабых секретов, необязательный wordlist и короткий брутфорс:

   ```
   python scripts/crack_hs256.py "<перехваченный-токен>"
   python scripts/crack_hs256.py "<токен>" --wordlist rockyou.txt
   python scripts/crack_hs256.py "<токен>" --brute --maxlen 6
   ```

   Вы должны восстановить `secret123`.
3. Как альтернатива, тот же секрет встроен в клиент: выполните `strings ApiClient.exe`
   или распакуйте архив PyInstaller и прочитайте модуль клиента.
4. Подделайте HS256-токен этим секретом с `"role":"admin"` и обратитесь к
   `/private/signed`.

Подсказка: `jwt.encode({"sub":"x","role":"admin"}, "secret123", algorithm="HS256")`.

Ожидаемый артефакт: подписанный токен вашей сборки, который сервер принимает.

## Задача 5 — Шифрованный токен (`/private/encrypted`)

1. Нажмите `/private/encrypted` и перехватите JWE (пять сегментов через точку).
   Обратите внимание на заголовок `{"alg":"dir","enc":"A256GCM"}` — это шифрование, а не
   подпись, поэтому jwt.io его НЕ декодирует.
2. Общий симметричный ключ тоже находится внутри клиента (значение 32 байта/256 бит).
3. Расшифруйте JWE этим ключом, измените payload и зашифруйте обратно. Можно использовать
   предоставленный хелпер:

   ```
   python scripts/jwe_helper.py decode "<перехваченный-токен>"
   python scripts/jwe_helper.py forge --role admin --sub hacker
   ```

4. Обратитесь к `/private/encrypted` с пересобранным токеном.

Ожидаемый артефакт: сервер расшифровывает и принимает ваш подделанный payload.

## Что сдать

Короткий отчёт по каждой задаче: перехваченный токен, внесённое изменение, использованный
инструмент и ответ сервера, подтверждающий успех.
